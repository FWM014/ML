How this book works

🧒 Explain it like I'm 9

Every new concept opens with a concrete analogy in a yellow box. Then the precise definition. Then the math (optional, purple boxes). Then code.

🎛️ Touch the ideas

Sliders and steppers let you move a threshold, walk gradient descent, grow a tree, or watch k-means converge. Intuition comes from playing.

💼 Built for work

Green "At work" boxes say what actually matters on the job: baselines, leakage, metrics that match decisions, and shipping models that survive contact with production.

⚠️ Common mistakes

Red boxes catalogue the errors practitioners make constantly. Learn them before you make them on a real project.

✅ Check yourself

Each chapter ends with a self-grading quiz, exercises with answers, and a summary checklist. Mark chapters done; progress is saved in your browser.

🐍 Real code

All examples use the tools you'll use at work: NumPy, pandas, scikit-learn, XGBoost/LightGBM, PyTorch, SHAP. Copy, run, adapt.

The curriculum map

Four parts, each a level. Part I gives you the vocabulary and the two fundamental models. Part II is the practical toolkit you will use for 80% of business problems. Part III is deep learning. Part IV is what separates practitioners from experts: explaining, shipping, monitoring, and running a project end-to-end.

At work: the fastest route to being useful

If you must ship something next week, read Chapters 1, 2, 6, 7, 8, 10, 13 and 23 in that order. That path gives you problem framing, leakage-proof data handling, the right metric, a gradient-boosting pipeline, honest validation, and a project playbook. Come back for the rest.

Prerequisites & setup

  • Python basics (variables, loops, functions, lists/dicts). Chapter 4 covers the data libraries from zero.
  • High-school math. Chapter 3 rebuilds everything else you need, gently.
  • Environment: Python 3.10+, then pip install numpy pandas scikit-learn matplotlib xgboost lightgbm shap statsmodels torch. Every code block in the book runs offline on these.
How to read a chapter
  1. Read the objectives. Skim the figures first; they carry the argument.
  2. Read the prose; play with every widget until you can predict what a slider will do.
  3. Run the code yourself. Change a number. Break it. Fix it.
  4. Take the quiz without looking back. Do at least the "at work" exercise.
  5. Tick "Mark as completed" and read the summary once more tomorrow.
